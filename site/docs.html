Install and Run

# Install via Brew -- COMING SOON

# Install script
curl -fsSL https://raw.githubusercontent.com/walkerbrown/goodwrite/main/scripts/install.sh | bash

# check
goodwrite check docs/**/*.md docs/**/*.typ

# fix machine-applicable diagnostics
goodwrite fix docs/manual.md

# create starter config template (optional)
goodwrite init config

# create starter glossary template (optional)
goodwrite init glossary

Config Defaults

goodwrite runs without goodwrite.toml.

  • Default profiles are ["asd-ste100", "ears", "glossary"].
  • goodwrite init config writes that profile list as commented lines and refuses to overwrite an existing config file.
  • goodwrite init glossary refuses to overwrite an existing glossary file.
  • Generated glossary examples are commented out, so sample entries are not enabled by accident.
  • If you uncomment profiles.enable, only the listed profiles are enabled.
  • When file-level mode annotations are missing, goodwrite emits goodwrite/missing-mode-annotation as an info diagnostic.
  • Use [unsafe].ignore globs to suppress that info diagnostic for selected files. These globs resolve relative to goodwrite.toml.
  • Configure requirement rulesets in goodwrite.toml.
  • Source annotations never select a ruleset.

Requirement Syntax

Requirement type vocabulary comes from active requirement rulesets (EARS by default).

Markdown

<!-- goodwrite:requirement -->
The system shall reset in less than 100 ms.
<!-- goodwrite:requirement:end -->

<!-- optional type -->
<!-- goodwrite:requirement:state-driven -->
While battery voltage is below 22.0 V,
the system shall reduce transmit power.
<!-- goodwrite:requirement:end -->

Typst

#requirement[
The system shall reset in less than 100 ms.
]

#requirement_state[
While battery voltage is below 22.0 V,
  the system shall reduce transmit power.
]
